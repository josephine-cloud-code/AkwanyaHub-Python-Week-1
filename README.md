What I Learned

Module 1 introduced the basic Python environment and the process of

The basic workflow I followed was:

Write the code
      ↓
Save the Python file

Run the program

Observe the output
      ↓
Identify and fix errors

Hello World!

My First Hands-on Practice

I also created a simple program:

print("Hisssssss...")

The program successfully produced:

Hisssssss...

This was my first practical experience writing and running a Python
instruction.

🛠️ Debugging Practice

One of the useful parts of Module 1 was learning what happens when
the code contains an error.

I deliberately changed:

print("Hisssssss...")

to:

prin("Hisssssss...")

Python returned a NameError because prin was not recognized as the
print() function.

I corrected it back to:

print("Hisssssss...")

and the program ran successfully again.

What I learned from this

This exercise taught me that:

Python is sensitive to spelling.
Error messages provide useful information.
A small typing mistake can stop a program from running.
Debugging involves finding the problem, correcting it, and running
the program again.
Key Lessons from Module 1

The main things I learned were:

How to run a Python program.

That making mistakes is part of the programming learning process.
Challenges I Encountered

One of my early challenges was understanding why a small change in

For example:

did not work because the function name was misspelled.

After correcting it to:

print("Hisssssss...")

the program worked.

This helped me become more comfortable with errors instead of being
afraid of them.
